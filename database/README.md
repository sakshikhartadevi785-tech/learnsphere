# LearnSphere database export

These valid JSON files contain the developed MongoDB data required by the assessment brief. References use fixed 24-character MongoDB ObjectId strings so relationships remain consistent when the seed script imports the files.

Import them with the provided command:

```bash
cd server
npm run seed
```

The import order is managed automatically by `server/seed/seed.js`.

Collections represented:

- `users`
- `categories`
- `instructors`
- `courses`
- `schedules`
- `enrollments`
- `contactmessages`

The runtime `sessions` collection is generated by `connect-mongo` after users log in or add courses to their session basket.
